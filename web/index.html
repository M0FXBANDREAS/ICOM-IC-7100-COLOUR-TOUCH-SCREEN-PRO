METER

Signal uses the IC-7100 S-meter. Power is a percentage of its output-meter scale. Power and SWR update during transmit initiated on the physical radio; this app does not key the transmitter.

VFO / MEMORY

VFO/memory labels show the last selection made by this app. Physical front-panel mode changes are not read back by this version.

RADIO MEMORY RECALL

Select a bank and channel, then READ or RECALL.

Reads stored memories and selects them. No memory-write, clear or delete commands are implemented.

REPEATER SHIFT / CTCSS

Shift and tones configure the physical radio. The app does not transmit. Tone functions generally apply to FM; unsupported combinations are rejected by the radio.

CI-V RF SIGNAL SWEEP

One sweep measures 61 frequencies using real S-meter readings. It switches to VFO, retunes the receiver and restores its VFO centre afterwards. Reception/audio changes while sweeping.

This is a Pi-driven CI-V sweep, separate from the IC-7100's physical band-scope button. It is not a native spectrum-data stream.

RECEIVE FILTER

Select a filter preset on your IC-7100.

Actual bandwidth follows your radio's filter settings for the current mode. No assumed bandwidth is displayed.

SETTINGS · HamTech M0FXB Modification

Receiver · CI-V radio settings

Settings are read progressively. — means not yet read or unavailable. Band/mode restrictions are enforced by the IC-7100. Levels are raw 0–255 CI-V units.

Live USB audio / waterfall
Waiting for audio

Received USB AF audio drives every FFT frame. CI-V carries control data. Choose AF output on the radio; adjusting radio speaker volume may not change USB AF level. These display controls do not change the radio DSP.

Display / tuning

View and size: top toolbar. Step: radio screen / QUICK. HOLD: freeze scope. EXPD: expanded spectrum. MENU → FULL SCREEN: fullscreen. Preferences save in this browser.

Connection information

Serial path, baud, CI-V address and audio input are launch options. Audio input: run .venv/bin/python -m sounddevice, then launch with --audio-device INDEX. Restart after changing launch options.
